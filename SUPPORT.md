# Soporte y Ayuda — Xynex Code Editor & Cibao

¿Necesitas ayuda para instalar, compilar o programar en **Cibao** (`.cibao` / `.alb`) con **Xynex Code Editor**?

## Recursos oficiales

1. **Documentación integrada:** Dentro del propio IDE puedes abrir **Ayuda → Documentación** para consultar los 8 manuales completos sin conexión.
2. **Guías en el repositorio:**
   - [Manual del lenguaje Cibao (`v5.0.0`)](docs/03_manual_del_lenguaje.md)
   - [Manual de Xynex Code Editor](docs/06_manual_del_ide.md)
   - [Guía de Addons](docs/07_guia_de_addons.md)
   - [Solución de problemas frecuentes](docs/08_solucion_de_problemas.md)
3. **Incidencias en GitHub:** Abre un reporte en [Issues de CynexStudios/alba-ecosistema](https://github.com/CynexStudios/alba-ecosistema/issues) indicando tu sistema operativo, versión de Xynex Code Editor y pasos para reproducir el problema.
