# 01. Introducción y Filosofía — Cibao Code 9.0 & Xynex Code Editor 9.0

Bienvenido a la documentación oficial completamente renovada de **Cibao Code 9.0** y **Xynex Code Editor 9.0**.

## ¿Qué es Cibao Code 9.0?

**Cibao Code** es un lenguaje de programación estructurado, expresivo y redactado íntegramente en español, diseñado tanto para quienes escriben su primer `"Hola Mundo"` como para proyectos modulares complejos con Programación Orientada a Objetos, manejo de JSON, lambdas flecha y módulos estándar.

- **Extensión oficial:** `.cibao` (100% retrocompatible con proyectos `.alb`).
- **Motor propio en .NET 8:** Intérprete de alto rendimiento sin dependencias externas para código Cibao.
- **Sintaxis limpia y moderna:** Bloques con llaves `{ ... }`, inferencia automática con anotación opcional (`: tipo`), interpolación de texto (`$"Hola {nombre}"`), rangos (`1..5`, `1..=5`), lambdas flecha (`x => x * 2`) y seguridad frente a valores `nulo` (`?.` y `??`).

## ¿Qué es Xynex Code Editor 9.0?

Es un **IDE de escritorio estilo Visual Studio** multiplataforma (Windows, Linux portátil, Arch Linux, CachyOS, Ubuntu, Fedora y macOS) que integra en una sola ventana:

1. **Edición sin carpetas obligatorias:** Crea y ejecuta archivos rápidos al instante sin tener que definir una carpeta primero.
2. **Entornos e Intérpretes Multi-Lenguaje Nativos:** Cibao Code 9.0, Python, HTML5, CSS3, JavaScript, TypeScript, JSON, C# (.NET) y C++20.
3. **IntelliSense y Detectores de Errores en Vivo Nativos:** Sugerencias de alto contraste y análisis instantáneo de errores sin depender de internet.
4. **Bot Tutor Automático (Desde Cero):** 8 lecciones interactivas dentro del editor para practicar cada tipo de dato, variable, ciclo, función y clase.
5. **Agente de IA Propio:** Conecta tus propias API Keys o modelos locales (Ollama, Google Gemini, OpenAI, DeepSeek, Groq o Claude) en una bóveda cifrada local.
6. **Tienda Online de Addons (API):** Descarga extensiones en 1 clic sin descargas manuales.
7. **Seguridad y Cuentas Propias en SQLite:** Registro e inicio de sesión local con hash PBKDF2-SHA512, bloqueo automático por intentos fallidos y cifrado AES-256-GCM / DPAPI.
8. **Actualizador Automático Silencioso:** Verifica firma SHA-256 y actualiza el programa automáticamente cuando sale una nueva versión.
