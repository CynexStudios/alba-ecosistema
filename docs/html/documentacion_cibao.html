1. Inicio y Filosofía 9.0

Cibao Code 9.0 es un lenguaje de programación moderno escrito en español, claro para principiantes y potente para aplicaciones reales. Su extensión oficial es .cibao (y mantiene 100% compatibilidad con proyectos anteriores .alb).

  • Sin carpetas obligatorias: Desde Xynex 9.0 puedes pulsar Archivo Sin Carpeta, escribir tu programa al instante y ejecutarlo con F5 sin crear proyectos ni rutas primero.
  • Multi-lenguaje nativo: Ejecuta y analiza errores en tiempo real para Cibao, Python, HTML5, CSS3, JavaScript, TypeScript, JSON, C# y C++20.
  • Bot Tutor + Agente IA propio: Aprende desde cero con el Bot Tutor integrado y conecta tu propia cuenta o clave de IA (Ollama local gratuita, Google Gemini, OpenAI o Claude) en la bóveda cifrada.

2. Tu Primer Programa y Salida por Consola

En Cibao 9.0 no necesitas una función principal obligatoria para empezar. Usa mostrar(...) o imprimir(...), y lee datos del usuario con leer().

// Comentario de una línea
/* Comentario de
   múltiples líneas */

mostrar("¡Hola Mundo desde Cibao Code 9.0!")
variable nombre = leer("¿Cómo te llamas? ")
imprimir($"Encantado de verte, {nombre}. Versión actual: {9.0}")

Cadenas multilínea: Usa triple comilla """...""" o bloques interpolados $"""...""" para escribir plantillas o textos largos.

4. Operadores Modernos, Rangos e Incrementos (Novedades 9.0)

  • Aritméticos y potencia: +, -, *, /, %, y potencia directa ** (ej: 2 ** 8 == 256).
  • Asignación compuesta y unarios: +=, -=, *=, /=, x++, x--.
  • Rangos nativos: 1..5 genera [1, 2, 3, 4] (exclusivo); 1..=5 genera [1, 2, 3, 4, 5] (inclusivo).
  • Seguridad contra nulos: Acceso seguro usuario?.perfil?.nombre y coalescencia nula valor ?? "respaldo".
  • Comprobación de tipo en ejecución: si dato es lista { ... }.
  • Lógicos en español y simbólicos: y / &&, o / ||, no / !.
variable potencia = 2 ** 10
variable perfil = { direccion: nulo }
variable ciudad = perfil?.direccion?.ciudad ?? "Santo Domingo"
variable pasos = 1..=4   // [1, 2, 3, 4]
variable esLista = pasos es lista
mostrar($"2^10={potencia}, ciudad={ciudad}, pasos={esLista}")

5. Condicionales, Elegir/Caso y Ciclos

// Condicional si / sino_si / sino
variable nota = 88
si nota >= 90 {
    mostrar("Sobresaliente")
} sino_si nota >= 70 {
    mostrar("Aprobado")
} sino {
    mostrar("Requiere práctica")
}

// Selector múltiple elegir / caso / defecto
variable comando = "compilar"
elegir comando {
    caso "iniciar", "arrancar":
        mostrar("Iniciando sistema...")
    caso "compilar" {
        mostrar("Compilación 9.0 lista")
    }
    defecto:
        mostrar("Comando desconocido")
}

// Ciclos para / mientras / repetir / detener / continuar
para indice en 1..=5 {
    si indice == 3 { continuar }
    mostrar($"Iteración {indice}")
}

variable vidas = 3
mientras vidas > 0 {
    vidas--
}

6. Funciones, Expresiones Lambda Flecha (=>) y Clausuras

En Cibao 9.0 puedes declarar funciones completas, funciones cortas en una línea con => y lambdas anónimas muy compactas.

funcion multiplicar(a: entero, b: entero = 2): entero {
    retornar a * b
}

// Forma concisa con flecha =>
funcion cuadrado(x: entero): entero => x * x

variable datos = 1..=6
variable paresDobles = datos
    .filtrar(x => x % 2 == 0)
    .mapear((x) => x * 10)

mostrar($"cuadrado(7)={cuadrado(7)} | pares={unir(paresDobles, ', ')}")

7. Listas, Diccionarios y Métodos de Punto

Las listas y diccionarios incorporan métodos encadenables y soporte directo para JSON.

variable frutas = ["mango", "chinola", "guineo"]
frutas.agregar("lechoza")
frutas.ordenar()

para nombre, idx en frutas {
    mostrar($"{idx}: {nombre.mayusculas()}")
}

variable usuario = { nombre: "Carlos", rol: "Dev" }
usuario["activo"] = verdadero
variable textoJson = json_a_texto(usuario)
mostrar(textoJson)

8. Clases, Herencia, Encapsulación, Errores y Módulos

clase Vehiculo {
    publico marca: texto
    privado kilometraje: entero = 0

    constructor(marca: texto) {
        este.marca = marca
    }

    publico funcion avanzar(km: entero) {
        este.kilometraje += km
    }

    publico funcion describir(): texto {
        retornar $"{este.marca} ({este.kilometraje} km)"
    }
}

clase Electrico extiende Vehiculo {
    publico bateria: entero
    constructor(marca: texto, bateria: entero) {
        super(marca)
        este.bateria = bateria
    }
}

intentar {
    variable auto = nuevo Electrico("Xynex EV", 98)
    auto.avanzar(120)
    mostrar(auto.describir())
} capturar (error) {
    mostrar($"Ocurrió una incidencia: {error}")
} finalmente {
    mostrar("Bloque finalizado.")
}
